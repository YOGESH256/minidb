What is what inside minidb

A database is a very careful filing clerk: it stores rows, finds them fast, and never loses anything, even if the power goes out mid-write. minidb is that clerk, built in seven layers of TypeScript. Click a layer to see what it does in plain words, then follow one INSERT all the way to disk.

7layers, each only talks to the one below
4 KBsize of one page, the unit everything is stored in
2files on disk: the data file and the log
34tests, including pulling the plug mid-write
